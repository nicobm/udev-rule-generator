Features

Small tool, focused job.

No background daemon and no automatic writes. You stay in control of every rule.

Detect

Finds USB and Bluetooth controllers through udevadm, with their name, VID:PID, serial, and input nodes.

Enable

Creates 10- rules with MODE="0660" and TAG+="uaccess" for input, USB, and hidraw access.

Ignore

Creates 99- rules that deauthorize USB devices or deny access to input nodes, so false positives stay out of your way.

Inspect

Inspect the exact rule with --dry-run, then enable, disable, or remove managed rules later.

GNOME

Built to feel at home.

The GUI uses GTK4 and libadwaita, with a clean card layout in the spirit of GNOME apps.

  • Detects controllers automatically with udevadm monitor and a periodic fallback.
  • Sends a GNOME notification when a controller connects.
  • Saves each configured device and its latest rule, so you can enable or disable it without plugging it in again.
  • Speaks English for en_US/en_GB, Spanish for every es_* locale, and falls back to English for other locales.

Install

Two ways to run it.

Use your distribution packages for a native install, or build the Flatpak with the included script.

Fedora / native

Requires Python, PyGObject, GTK4, libadwaita, and polkit. 

sudo dnf install python3-gobject gtk4 libadwaita polkit
bash install-native.sh
udev-rule-generator --gui

Flatpak

Uses the GNOME 51 runtime and the included build script. 

bash build-flatpak.sh
flatpak run io.github.nicobm.UdevRuleGenerator

See the README for requirements, CLI usage, and troubleshooting.

Optional presets

Two sources. Both off by default.

Presets are copied only when you select them. They are never installed during package installation.

game-devices-udev

27 vendor rules from Fabian Bornschein (fabiscafe). MIT licensed. Installed as a complete package or not at all.

View on Codeberg

steam-devices

Valve's Steam Input and SteamVR rules. MIT licensed. Installed together as one package.

View on GitHub

The app ships reviewed snapshots and never downloads rules at runtime. Maintainers can refresh them with tools/update_presets.py.
